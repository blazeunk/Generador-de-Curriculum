# 📄 Generador de Currículum Vitae

Un generador práctico y personalizable para crear currículums profesionales de forma rápida, estructurada y limpia.

---

## 🚀 Características

- 📝 **Fácil de usar:** Completa los datos requeridos y genera tu CV de manera automatizada.
- 🎨 **Diseño Limpio & Profesional:** Plantilla optimizada para destacar tu experiencia laboral y habilidades.
- ⚡ **Rápido y Liviano:** Carga inmediata sin dependencias complejas.
- 📱 **Diseño Adaptable (Responsive):** Funciona perfectamente en computadoras y dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del documento.
- **CSS3:** Estilos visuales, diseño responsive y formato listo para impresión/exportación.
- **JavaScript:** Lógica de generación dinámica de contenido.
